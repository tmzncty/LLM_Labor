# LLM Labor — AI 幕后的人

记录大模型时代的劳动真相。

ChatGPT 的"安全"是用肯尼亚标注员的心理健康换来的。Stable Diffusion 的"创意"让插画师的收入缩水 80%。Klarna 用 AI 替代了 700 名客服，没有人记录他们去了哪里。

这个项目要做的事很简单：**记录 AI 幕后那些不可见的人——他们的劳动、他们的失去、他们的抵抗。**

## 结构

**调查**记录事实——标注员、审核员、数据清洗员的工作条件和生存状况。
**冲击**记录失去——被 AI 冲击的行业和职业，从翻译到插画到客服到初级编程。
**转型**记录应对——谁适应了、谁离开了、谁在反抗、谁在被遗忘。
**论**载分析——劳动正义、AI 伦理、技术与人的关系。
**表**备速查——受冲击职业清单、标注产业链地图、裁员时间线、政策对比。

## 体例

全书白话文。每一条记述必须注明出处——新闻 URL、调查报告、访谈记录，能查回去。
不确定的标注"存疑"，不编造。
人名首次出现注其身份和来源。
叙事与议论分离——先讲故事，再做分析。

详细规范见 [`00_体例.md`](00_体例.md)。

## 为什么记这些

因为没人记。

LLM_Chronicle 记录了模型的历史——谁发了什么模型、融了多少钱、涨了多少参数。那些是聚光灯下的故事。但每一行 RLHF 训练数据的背后，都有一个真人坐在屏幕前，标注"这个回答好，那个回答不好"。他们拿着 $1-2 的时薪，阅读人类最黑暗的产出——暴力、色情、仇恨——然后教会 AI 说"我不能帮你做这个"。

这些人的故事不在任何技术论文里，不在任何融资公告里，不在任何 benchmark 排行榜上。如果没人写下来，它们就会像所有不可见的劳动一样，被历史吞没。
