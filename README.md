# LLM Labor — AI 幕后的人

> **AI 不是无劳动的。** 这里记录训练模型、审核内容、生产数据、复核 Agent、被重构职业路径，以及重新谈判 AI 使用条件的人。

LLM Labor 是持续维护的 **AI 劳动史料库**，不是“AI 会不会抢工作”的观点合集。
