# LLM Labor — AI 幕后的人

> **AI 不是无劳动的。** 这个仓库记录训练模型的人、审核内容的人、复核 Agent 的人、被改变职业路径的人，以及试图重新谈判技术使用条件的人。

本项目是持续维护的 **AI 劳动史料库**，不是“AI 会不会抢工作”的观点合集。目标是把劳动链、合同、工资、任务、组织变化和制度回应写成可回查的记录。

## 来源与素材

`sources/` 是来源元数据和 claim 映射层，不是新闻全文镜像。`review/` 是历史研究素材区，不能因为“已经在仓库里”就自动当成已核事实。

## 维护原则

1. 有据则书，无据则阙。
2. 不编造匿名人物、直接引语、数字和 URL。
3. 公司归因、相关性和独立因果证据分开写。
4. 工资、健康、违法、裁员归因等高风险结论优先双源。
5. 主动收录反证。
6. 新正式中文条目同步维护英文版。
7. 不新增中国大陆相关议题。
8. **允许 HOLD。证据不足不是失败，硬写才是。**
