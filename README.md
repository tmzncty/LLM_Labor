# LLM Labor — AI 幕后的人

> **AI 不是无劳动的。** 这个仓库记录训练模型的人、审核内容的人、复核 Agent 的人、被改变职业路径的人，以及试图重新谈判技术使用条件的人。

本项目是持续维护的 **AI 劳动史料库**，不是“AI 会不会抢工作”的观点合集。目标是把劳动链、合同、工资、任务、组织变化和制度回应写成可回查的记录。

**当前版本：2026-08-28 v2**  
**正式文章：55 篇（调查 14 / 冲击 17 / 转型 10 / 论 8 / 表 6）**  
**v2 已审计：18 篇；历史旧稿待审计：37 篇。** 篇数不等于事实质量，状态见 [`docs/AUDIT_LEDGER.md`](docs/AUDIT_LEDGER.md)。

> **范围约束：从 2026-08-28 起，不新增中国大陆相关议题。** 详细边界见 [`SCOPE.md`](SCOPE.md)。

## v2 已经纠正的典型旧问题

- 把“工作量等效”误写成具体裁员人数；
- 把自愿行业调查误写成总体就业率；
- 把心理困扰量表误写成 PTSD 患病率；
- 把单项医疗 benchmark 误写成“AI 已超过医生”；
- 把游戏行业整体裁员全部归因于生成式 AI；
- 编造化名劳动者、采访和报价；
- 只写域名、不写可回查文章；
- 把未来计划、预测、招聘冻结和已执行裁员直接相加。

## 来源与素材

`sources/` 是来源元数据和 claim 映射层，不是新闻全文镜像。`review/` 是历史研究素材区，不能因为“已经在仓库里”就自动当成已核事实。

## 维护原则

1. 有据则书，无据则阙。
2. 不编造匿名人物、直接引语、数字和 URL。
3. 公司归因、相关性和独立因果证据分开写。
4. 工资、健康、违法、裁员归因等高风险结论优先双源。
5. 主动收录反证。
6. 新正式中文条目同步维护英文版。
7. 不新增中国大陆相关议题。
