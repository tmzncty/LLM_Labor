# LLM Labor — AI 幕后的人

> **AI 不是无劳动的。** 这个仓库记录训练模型的人、审核内容的人、复核 Agent 的人、被改变职业路径的人，以及试图重新谈判技术使用条件的人。

本项目不是“AI 会不会抢工作”的观点合集，而是一个持续维护的 **AI 劳动史料库**：尽量把劳动链、合同、工资、任务、组织变化和制度回应写成可回查的记录。

**当前版本：2026-08-28 v2**  
**正式文章：55 篇（调查 14 / 冲击 17 / 转型 10 / 论 8 / 表 6）**  
**v2 已审计：11 篇；历史旧稿待审计：44 篇。** 篇数不等于事实质量，旧稿状态见 [`docs/AUDIT_LEDGER.md`](docs/AUDIT_LEDGER.md)。

> **范围约束：从 2026-08-28 起，不新增中国大陆相关议题。** 详细边界见 [`SCOPE.md`](SCOPE.md)。

## 结构

**调查**：谁在训练、审核、标注、评测 AI，以及这些工作的合同与条件。  
**冲击**：AI 改变了哪些职业任务、招聘入口、收入与组织结构。  
**转型**：劳动者、公司、工会怎样适应、抵抗、监督和重新谈判。  
**论**：在事实底座上讨论劳动正义、数字劳动与组织重构。  
**表**：时间线、供应链、职业与政策速查。

## 2026 这一轮新增了什么

这一版把“AI 劳工”从早期的低薪数据标注扩展成更完整的劳动分层：

- 专家把律师、顾问、创作者、学科知识变成训练信号；
- 非洲跨国外包链让“谁在为谁工作”本身变得模糊；
- 体育数据工把现实世界逐帧翻译成机器可读事件；
- Outlier 把专业判断平台化、任务化；
- 美国年轻人的高 AI 暴露岗位首先出现**招聘入口**分化；
- 印度 IT 服务业从“按多少人”向“按结果”计价；
- Agent 让一部分工作从执行转成监督、复核、异常处理与责任承接；
- SAG-AFTRA 把数字替身的同意、用途和报酬写进集体协议；
- 新的理论篇把研究问题从“有没有替代”推进到“组织怎样重新组合工作”。

## 来源与素材

`sources/` 是**来源元数据层**，不是新闻全文镜像。新条目会记录来源等级、检查日期和支持的 claim。新闻正文默认不整页复制，公开合同、政府文件、论文和数据集在许可与必要性允许时再归档。

`review/` 是历史研究素材区。**其中内容不能因为“已经在仓库里”就自动当成已核实事实。** 使用前必须回到原始来源。

## 维护原则

1. 有据则书，无据则阙。
2. 不编造匿名人物、直接引语、数字和 URL。
3. 把“公司说 AI 导致”与“独立证据证明 AI 导致”分开。
4. 工资、健康、违法、裁员归因等高风险结论优先双源。
5. 主动收录反证；例如 2026 年 Stanford 数据同时显示“青年入口岗位出现分化”和“尚无全经济大规模就业崩溃”。
6. 新正式中文条目同步维护英文版。
7. 不新增中国大陆相关议题。

## 为什么记这些

模型史容易记：参数、融资、发布日、排行榜都有现成记录。

劳动史更容易消失。一个模型学会拒绝有害请求之前，可能有人先读过大量有害样本；一个 Agent 能跑完流程以后，可能有人长期帮它设计环境、纠错、复核；一个职业仍然存在时，新人入口可能已经缩小；一个数字替身可以无限复用时，演员必须重新谈判“一次表演”到底意味着什么。

这些变化如果只等到“职业消失”才记录，就已经晚了。
