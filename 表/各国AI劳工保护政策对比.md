# 表·各国 AI 劳工保护政策对比

> 编制：白面鸮 | 更新：2026-06-21

## 1. 总体对比

| 国家/地区 | AI 劳工保护立法 | 平台工人保护 | 算法透明要求 | 最低工资保障 | 心理健康保护 | 出处 |
|-----------|----------------|--------------|-------------|-------------|-------------|------|

| 美国 | **无**（联邦层面） | **弱**（独立承包商为主） | **无**（联邦层面） | **无**（平台工人） | **无** | 美国劳工部 |

## 2. 欧盟：领先立法

### AI Act（2024 年通过）

| 内容 | 说明 |
|------|------|
| 高风险 AI 系统 | 用于招聘和人力资源管理的 AI 必须进行合规评估 |
| 透明度要求 | 劳动者有权知道自己是否被 AI 评估 |
| 禁止事项 | 禁止在工作场所使用"不可接受风险"的 AI 系统 |
| 生效时间 | 2026 年全面生效 |

### 平台工作指令（2024 年通过）

| 内容 | 说明 |
|------|------|
| 推定雇员身份 | 推定平台工人为"雇员"，除非平台能证明相反 |
| 算法透明 | 平台必须向工人解释算法如何分配任务、评估绩效、决定报酬 |
| 禁止算法解雇 | 解雇必须由人类做出 |
| 健康保护 | 平台必须提供职业安全和健康保护 |
| 生效时间 | 2026 年前各成员国需转化为国内法 |

来源：European Parliament[^1]

## 3. 美国：碎片化与观望

### 联邦层面

| 事件 | 说明 |
|------|------|
| 拜登 AI 行政命令（2023-10） | 要求"保护工人免受 AI 驱动的伤害"，但不具法律约束力 |
| 国会法案 | 多项 AI 相关法案未获通过 |

### 州层面

| 州 | 法案 | 内容 | 状态 |
|----|------|------|------|
| 加州 | AB5（2020） | 限制"独立承包商"的使用 | 生效，但 Prop 22 豁免了部分平台 |
| 加州 | Prop 22（2020） | 豁免 Uber、Lyft 等平台 | 生效 |
| 纽约市 | Local Law 144（2023） | 要求 AI 招聘工具进行偏见审计 | 生效 |
| 伊利诺伊 | BIPA | 生物信息隐私法 | 生效 |

来源：各州政府网站[^2]

## 4. 中国：发展优先

| 领域 | 法规/政策 | 内容 | 出处 |
|------|----------|------|------|
| AI 生成内容 | 《生成式人工智能服务管理暂行办法》（2023） | 关注内容安全，未涉及劳动 | 网信办[^3] |
| 新就业形态 | 《关于维护新就业形态劳动者劳动保障权益的指导意见》（2021） | 鼓励平台保障劳动者权益，但无强制力 | 人社部[^4] |
| 数据安全 | 《数据安全法》（2021） | 关注数据安全，未涉及劳动 | 全国人大[^5] |

**特点**：
- 优先发展 AI，劳动保护为辅
- 新就业形态劳动者保护以"指导意见"为主，无强制力
- 平台工人（外卖骑手、网约车司机）的劳动关系认定仍有争议

## 5. 标注产业重镇：监管真空

### 肯尼亚

| 项目 | 说明 |
|------|------|
| 最低工资 | 约 $1.15/小时（因行业和地区而异） |
| 标注员时薪 | $1.32-$2（高于最低工资，但远低于美国标准） |
| 专门立法 | 无 |
| 调查 | 2023 年政府调查 Sama，结果未公布 |
| 工会 | 无 |

### 菲律宾

| 项目 | 说明 |
|------|------|
| 最低工资 | 约 $0.80-1.20/小时（因地区而异） |
| 标注员时薪 | $1.50-$3 |
| 专门立法 | 无 |
| 工会 | 有限 |

### 印度

| 项目 | 说明 |
|------|------|
| 最低工资 | 因邦而异，约 $0.30-0.80/小时 |

| 专门立法 | 无 |

来源：ILO[^6]

## 6. 国际组织

| 组织 | 立场 | 具体建议 | 出处 |
|------|------|----------|------|
| 国际劳工组织（ILO） | 呼吁保护平台工人 | 将平台工人纳入劳动保护范围、算法透明、跨境劳动保护 | ILO 2024[^7] |
| 联合国 | 呼吁公平分配 AI 收益 | 确保 AI 服务于所有人 | 联合国 2024[^8] |
| OECD | 制定 AI 原则 | 以人为本、透明、可问责 | OECD 2024[^9] |

## 7. 政策空白

| 领域 | 全球现状 | 影响 |
|------|----------|------|
| 标注员心理健康 | 几乎无保护 | PTSD、焦虑、抑郁不被视为工伤 |
| 算法透明（全球南方） | 无要求 | 标注员不知道算法如何影响自己的工作 |
| 跨境劳动保护 | 无框架 | 标注员在肯尼亚，AI 公司在美国，无管辖权 |
| AI 导致的失业补偿 | 无制度 | 被 AI 替代的工人没有补偿 |
| 数据标注行业标准 | 无统一标准 | 不同平台的劳动条件差异巨大 |
