# Claim Standard — 事实与判断分级

## 1. 四类陈述

### A. 已证实（Documented）

满足其一：

- 一手文件直接支持；
- 原始数据/论文直接支持；
- 两个相互独立的高质量来源一致支持。

可使用肯定句，但仍要保留时间、地区、样本与口径。

### B. 有力支持（Well-supported）

由一个高质量调查报道、可靠研究机构或具名材料支持，但尚未双源验证。

正文可写事实，但避免扩大到来源未覆盖的范围。

### C. 单源 / 待核（Single-source / Pending）

只有单个采访、公司自述、单个劳动者证词、行业传闻或无法独立复核的数据。

必须明确写“据……报道/称/估计”“尚缺独立验证”。不得升级成普遍规律。

### D. 分析（Analysis）

作者对事实的解释、理论框架、价值判断和比较。

必须与事实段分开，不能伪装成来源已经证明的结论。

## 2. 数字规则

任何数字至少回答：

- 什么时候？
- 在哪里？
- 谁统计的？
- 分母是什么？
- 是人数、岗位、招聘、收入、工时、估值还是样本比例？

禁止：

- 把“订单减少”写成“收入减少”；
- 把“某平台任务报价”写成“行业平均工资”；
- 把“公司宣布自动化目标”写成“已经完成替代”；
- 把“岗位数下降”直接写成“AI 导致失业”。

## 3. 因果规则

以下句式需要高证据门槛：

- “AI 导致……”
- “因为 AI，所以裁掉……”
- “模型替代了 X 人”
- “某技术使某行业收入下降 X%”

如果只能确认公司自己这样解释，应写：

> 公司将该调整归因于 AI / 自动化，但现有公开资料不足以把全部变化归因于 AI。

## 4. 健康与伤害

心理健康、PTSD、抑郁、职业伤害等属于高风险结论。

- 个人自述只能写“出现……症状/自述受到影响”；
- 只有医学诊断或研究数据才能写“患有/比例为”；
- 不得把少数采访对象外推成全部劳动者。

## 5. 引语

- 不创造“标注员 A/B/C”并给其编写台词；
- 不把转述包装成直接引语；
- 原文引语只保留论证所需的最短片段；
- 中文译文应注明“译自原文”，不能改变语气强度。

## 6. 时间敏感性

公司估值、平台工资、劳动协议、裁员数字、政策状态都可能很快变化。此类条目必须标“截至 YYYY-MM-DD”。

## 7. 每篇文章的最小证据单元

正式文章至少应包含：

1. 一句可核查的核心结论；
2. 至少一个 A/B 来源；
3. 一段“我们知道什么”；
4. 一段“我们不知道什么 / 不能据此断言什么”；
5. 来源列表；
6. 若存在分析，明确置于“评曰/分析”部分。
